## 8.2 防機器人 Turnstile（已實作，dev 已啟用）

## 8.5 登入時效（Session 有效期）

兩套登入各自獨立的 KV session（cookie：後台 `paa_admin`／會員 `paa_member`），皆為「滑動式」——持續操作會自動續期，閒置才到期：

- **會員**：閒置 **2 小時** 自動登出（每次操作即續期）。
- **後台（管理者）**：閒置 **60 分鐘** ＋ **絕對上限 12 小時**（不論是否活躍，登入滿 12 小時一定要重登）；後台 cookie 為 `SameSite=Strict`（會員為 `Lax`）。
- 續期採「壽命過半才刷新 KV TTL」以壓低寫入；時間長度可於 `api/src/auth.ts`（後台）與 `api/src/member.ts`（會員）的 `*_TTL` 常數調整。
- 逾時體驗：前台會員操作中遇逾時 → 自動導回登入頁並提示；後台則彈出**就地重新登入視窗**，未存的編輯內容仍保留，重新登入後再按一次「儲存」即可送出。

## 8.6 交易信（Cloudflare Email Service — Email Sending）

發信走 Cloudflare Email Service 的 **Workers 綁定**（`env.EMAIL`），沒有 API key 要保管，SPF／DKIM／DMARC 由 Cloudflare 託管。網域 `paa.org.tw` 已在 PAA 帳號完成開通（`cd api && npx wrangler email sending list` 可查）。寄件者固定 `noreply@paa.org.tw`，且 `wrangler.jsonc` 的 `allowed_sender_addresses` 已把綁定限死在這個位址。

**目前寄哪些信**（全部集中在 `api/src/email.ts`）：

| 觸發點 | 收件者 | 內容 |
| --- | --- | --- |
| 民眾送出線上入會申請 | 申請人 | 收件確認 ＋ 預審編號（送出頁關掉就找不回來，這封信是唯一留存） |
| 同上 | 公會信箱 | 辦理通知 ＋ 申請摘要 ＋ 後台連結；`Reply-To` 指向申請人 |
| 後台核准入會 | 申請人 | 審核通過 ＋ 會員編號 ＋ 入會日期 |
| 後台改為退件 | 申請人 | 審核未通過 ＋ 審核說明 |

公會信箱取自後台「聯絡資訊」設定（`settings.contact.email`），改後台即改收件者，不需重新部署。

### 收件人的兩道關卡（`MAIL_REDIRECT_TO`）

順序很重要，`api/src/email.ts` 的 `sendMail()`：

1. **`MAIL_REDIRECT_TO` 一設就全面改導，不分環境。** 這是總開關 —— 正式站上線初期先讓所有通知信落到自己信箱、確認內容無誤再對外開；確認完把 secret 刪掉即恢復正常。可用逗號分隔設定多個收件人（如 `a@x.com,b@y.com`）。
2. 沒設改導、且非 prod → **完全不寄**（日誌印 `[mail:skipped]`）。測試站資料庫含真實會員個資，誤寄代價遠大於少測一封信。

```bash
cd api
npx wrangler secret put MAIL_REDIRECT_TO --env dev     # 開發實測
npx wrangler secret put MAIL_REDIRECT_TO --env prod    # 上線初期的安全閥
npx wrangler secret delete MAIL_REDIRECT_TO --env prod # 確認無誤後，開始真的對外寄
```

改導期間主旨會標上原收件者（`[prod → 某某@example.com] …`），一眼看得出這封信原本要給誰。**這些位址若先在 Cloudflare 帳號內驗證過（Email Routing 的 destination address），這些信不計費也不佔每月額度。**

> ⚠️ 這段邏輯早期寫成 `if (ENVIRONMENT !== 'prod') { …改導… }`，等於在 prod 設了 secret 也毫無作用、信照樣寄給真人 —— 正是這個開關要防的事。修改此處務必確認 prod 也吃得到。

**費用**：Workers Paid 每月含 3,000 封，超出 $0.35／1,000 封。本站量級（入會申請一年數十件）實質 $0。

**寄送失敗怎麼查**：一律 best-effort（背景執行、吞錯），不會讓申請送出或後台核准失敗。查 Worker 日誌的 `[mail:failed]`，看 `code`：`E_SENDER_NOT_VERIFIED`（網域沒開通）、`E_RECIPIENT_SUPPRESSED`（對方退過信或按過垃圾信，需到 dashboard 的抑制名單處理）、`E_DAILY_LIMIT_EXCEEDED`（新帳號每日配額，可申請調高）。

## 8.7 會員忘記密碼（自助重設）

**政策：僅會員可自助重設；後台管理者一律人工重設。** 管理者帳號價值高、人數少，人工核身可行，沒有理由把它的安全性外包給某個可能多年沒更新的信箱。管理者忘記密碼仍照 §3 的 SQL 流程處理。

**流程**：前台會員登入頁「忘記密碼？」→ 輸入登入帳號或 email → 收信 → 點連結設新密碼 → 回登入頁以新密碼登入（**不自動登入**）。

**票券設計**（`api/src/auth.ts` 的 `pwResets`）：

| 性質 | 做法 | 為什麼 |
| --- | --- | --- |
| 短命 | KV `expirationTtl` 30 分鐘 | 信箱事後被存取，過期票券無用 |
| 單次 | 用掉即 `delete` | 同一封信不能重設第二次 |
| 只存雜湊 | KV key 為 `pwreset:<SHA-256(票券)>` | KV 內容外洩（備份、誤讀）拿到的是雜湊，反推不出可用連結 |
| 綁 `token_version` | 票券記發放當下的值，不符即作廢 | 期間密碼若已由其他管道變更，舊信不該還能改掉新密碼 |
| 重設即撤銷 session | 成功後 `token_version+1` | 帳號若已被他人登入，重設把他踢出去 |

**防帳號列舉**：`POST /api/member/forgot-password` **不論帳號是否存在，回應完全相同**（`{ok:true}`、同狀態碼、同回應時間——票券產生與寄信都在背景執行）。前端成功訊息也刻意寫成「若…相符，已寄出」。**改動這個端點時務必維持這個性質**，否則它會變成查詢會員身分的工具。

**節流**：每 IP 每小時 5 次、每帳號字串每小時 3 次（防灌信箱）、加 Turnstile。重設端點每 IP 10 次，且只有「票券猜錯」才計數——密碼不合規不該把人鎖在門外。

**稽核**：`audit_logs` 記 `password-reset-requested`（含查無此人的情形，entity_id 為輸入字串）與 `password-reset`。

**尚未自助的情形**：帳號未啟用（`account_enabled=0`，即尚未核發過初始密碼）、已退會、或會員資料沒留 email —— 這些一律靜默略過（回應仍相同），需洽秘書處。

## 8.8 入會申請書套印 PDF（Cloudflare Browser Rendering）

線上入會申請送出後，依填寫內容套印本會制式的四張表格（表格一入會申請書／表格二會員資料調查表／表格三委託書／表格四印鑑登記卡），供申請人列印、簽章、用印後送件。

**排版與產生**：`api/src/join-form.ts` 產生一份 A4 的 HTML，兩條路徑共用同一份排版 —— 直接回瀏覽器預覽列印，或交給 Browser Rendering 轉成 `.pdf`。共用是刻意的，否則會出現「畫面對、下載的 PDF 卻跑版」這種只在其中一條路徑才看得到的問題。

**刻意留白**：簽章、印鑑、相片（未上傳時）、承辦用的批示／複核／擬辦、會員編號、入會日期。這些本來就要列印後親簽用印或由公會填寫。

**取得方式**：

| 對象 | 路徑 | 授權 |
| --- | --- | --- |
| 申請人 | `/api/join-applications/form.pdf?token=…` | 送出時發的票券（KV，7 天、可重複用、只存雜湊）。同一連結也放進確認信。 |
| 承辦人 | `/api/admin/join-applications/:id/form.pdf` | 後台登入 |

不以預審編號當鑰匙：編號印在信與頁面上、格式可猜，而這份表單含身分證字號。兩條路徑都回 `Cache-Control: private, no-store`，公開 API 的邊緣快取中介層也明確排除了 `/api/join-applications/form`。

**大頭照**：線上表單可選填上傳，前端先縮到長邊 900px 的 JPEG（手機直拍動輒 4–8MB）。存 R2 的 `member/join/` 前綴 —— 公開的 `/files/*` 一律拒絕該前綴，因此沒有任何公開網址取得到；套印時由 Worker 讀出、以 `data:` URI 內嵌，連下載連結都不需要存在。**上傳不另開端點**：照片隨申請一起送，受同一道 Turnstile 與速率限制保護，不會多出一條免登入就能寫入 R2 的路徑。

**設定需求**：`wrangler.jsonc` 的 `browser` 綁定 ＋ **`compatibility_flags: ["nodejs_compat"]`**（`@cloudflare/puppeteer` 會 import `node:buffer`，缺旗標 Worker 一啟動就掛）。dev 的綁定加了 `remote: true`，本機沒有瀏覽器可模擬，`wrangler dev` 得直接用雲端工作階段才測得到真正的輸出。

**字型**：無頭 Chrome 不保證裝了中文字型，排版靠 Google Fonts 的 Noto Serif TC，並以 `waitUntil: 'networkidle0'` 等字型下載完才截圖，否則會印出整頁豆腐字。單份 PDF 約 1.3MB，主因是內嵌的中文字型子集。

**失敗時**：瀏覽器工作階段可能被限流或暫時不可用，此時端點改回傳 HTML 版（記 `[join-form:pdf-failed]`），使用者仍印得出來，不會整條路斷掉。

> ⚠️ 表格二的「實際擁有專業證照」勾選清單在兩處各有一份：`api/src/join-form.ts` 的 `QUALIFICATIONS` 與 `web/assets/app.js` 的 `quals`。**兩邊必須逐字一致**，否則使用者勾了卻印不出來，而且不會有任何錯誤訊息。
